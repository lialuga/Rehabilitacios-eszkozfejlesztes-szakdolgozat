GYAKORI PROBLÉMÁK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Metro port már használt"
   ✅ Megoldás: lsof -ti:8081 | xargs kill -9

❌ "Database error / DATABASE_URL nincs"
   ✅ Megoldás: Nézd meg DATABASE_SETUP.md

❌ "Pod install fail"
   ✅ Megoldás: cd ios && rm -rf Pods && pod install && cd ..

❌ "Szimulator nem indul"
   ✅ Megoldás: open -a Simulator

❌ "Red screen az appban"
   ✅ Megoldás: Nézd meg a Metro konzol outputot (hibák ott)
